# Online Demo

Try Oh-my-rime in your browser. A package can contain several input schemes; use “Input scheme” to switch after loading. Available schemes and features depend on the package you choose.

::: tip Getting started

1. Download the [Oh-my-rime online demo package (ZIP)](https://cnb.cool/Mintimate/rime/oh-my-rime/-/releases/download/latest/oh-my-rime-online.zip). Keep it zipped.
2. Drop the ZIP into the area below, or click to choose it, then wait for “Loaded”.
3. On a computer, switch your system input method to **ABC / English**, then choose an input scheme and start typing. This prevents the system and web input methods from processing the same keystrokes.

Friendly build: you can also load the [rime-ice online demo package](https://cnb.cool/Mintimate/rime/DocVitePressOMR/-/releases/latest/download/rime-ice-online.zip). The examples on this page follow Oh-my-rime; input codes may differ in other packages.

:::
